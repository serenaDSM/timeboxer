# TimeBoxer Mac 单机保护审计（0.6.4）

本文件说明孩子 Mac 尚未与家长 iPhone 绑定时，当前测试版能保护什么、如何验证，以及普通 macOS 应用暂时无法跨越的系统边界。

## 未绑定时已经生效

- 安装后本地扫描 `/Applications`、`/System/Applications` 和当前用户的 `Applications` 目录。
- 自动监测 TimeBoxer 已知的娱乐 App，以及 `LSApplicationCategoryType` 被 macOS 标记为 Games 的 App。
- 每 60 秒重新扫描；新启动的系统分类游戏也会即时加入本地提醒范围。
- 没有 Play 倒计时时，检测到娱乐 App 会立即显示不可直接忽略的全屏 Focus Shield，并持续播放警报音；游戏进程保留在后台，不会被退出或强制终止。
- Shield 只提供 `Earn more time`、`Ask parent` 和 `Return to TimeBoxer`。孩子重新切回娱乐 App 时会立即再次霸屏，不能用确认按钮直接回到游戏。
- Safari 和 Chrome 的默认视频、流媒体、网页游戏平台在非 Play 时间触发相同霸屏和警报，默认不会替换标签页或关闭浏览器。
- 浏览器自动化权限缺失时会以 Focus Shield 提醒孩子和家长“浏览器监管不可用”，但不会强制关闭浏览器。
- Play 只在原生绝对截止时间之前视为已批准娱乐；Play 期间不警报，应用重新启动或正常退出后会撤销残留的 Play 许可。
- Mac 已与家长端绑定且网络可用时，App/网站提醒事件会上传云端，并在家长端打开或刷新时显示。目前尚未接入 APNs，因此家长 App 完全关闭时还不会出现 iOS 系统推送横幅。
- Earn 进入 macOS 原生全屏保护。切换 App、退出全屏或全屏未恢复会暂停倒计时、持续循环警报并拉回 TimeBoxer；返回并确认后才继续。
- Mac 休眠、屏幕休眠或用户会话挂起会暂停 Earn，但不会把系统休眠误报成孩子切屏，也不会在休眠期间计入 Earn。
- 不再接受公开默认 PIN `1234`；首次使用必须先通过 macOS 管理员授权，再由家长创建 4–8 位私密 PIN，避免孩子抢先设置一个自己知道的 PIN。
- 发布菜单已移除调试用的 Demo Shield 和手动重载本地策略入口。

## 系统级边界

以下能力不能由当前这种普通、非特权 macOS App 可靠保证，不能向测试家庭表述为“无法绕过”：

- 同一 macOS 用户通过“强制退出”、活动监视器或终端结束 TimeBoxer 后，普通 App 无法保证自行存活。正式强化需要带授权的常驻辅助服务，或由 MDM 管理设备。
- 保护当前 macOS 用户会话，不会自动覆盖这台 Mac 上的其他用户。切换到另一个未安装、未启动 TimeBoxer 的用户会绕过当前版本。多用户全机保护需要特权系统服务或 MDM。
- 当前本地策略和家长 PIN 属于内测级本地数据；熟悉本机文件和调试工具的同账户用户仍可能篡改。正式抗篡改需要把敏感校验迁入 Keychain/特权辅助服务，并使用稳定的 Developer ID 签名。
- App 可以把自身警报音量设为最大，但不能绕过 macOS 的静音、系统输出音量、拔掉扬声器或切换音频输出。
- 浏览器网址识别需要家长在系统设置中允许 TimeBoxer 控制 Safari/Chrome；未授权时只能报告监管不可用，无法准确判断当前网站。
- 没有标准游戏分类且不在已知名单中的独立 App，单机模式不会仅凭名称猜测并误杀。绑定后家长可以从实际 App 清单中选择；后续可加入本地家长审核页。

## 首批家庭内测的 Mac 前提

- 孩子使用一个标准、非管理员 macOS 账户，家长保管管理员密码。
- TimeBoxer 安装在 `/Applications`，并允许“登录时打开”。
- 在孩子实际使用的每个 macOS 账户中分别安装/启用；学校管理账户需要先确认学校策略允许安装和运行。
- 家长首次在孩子 Mac 上创建私密 PIN，不把 PIN 或管理员密码告诉孩子。
- Safari/Chrome 首次出现自动化授权时由家长允许。
- 首轮先按文末手测清单验证，再进行 iPhone 绑定和远程策略/提醒测试。

## 0.6.4 必测清单

1. 不绑定家长端，启动 TimeBoxer，确认首次创建 PIN 会先要求 macOS 管理员授权，并拒绝 `1234`。
2. 不启动 Play，打开已安装的游戏：约 1–3 秒内应被 TimeBoxer Focus Shield 覆盖并持续响铃；游戏进程本身不应被关闭。
3. Shield 不应出现 `I understand`；点击 `Return to TimeBoxer` 后停止警报，再次切回同一个游戏应立即再次霸屏。
4. 不启动 Play，用已授权自动化权限的 Chrome/Safari 打开 YouTube：应出现相同霸屏和警报，但标签页和浏览器不应被强制关闭。
5. Mac 与家长端绑定后重复以上操作，刷新家长端应看到“activated the focus shield”提醒。
6. 启动任意 Earn（不需要等倒计时完成），立即使用 `Command-Tab` 切换到游戏：Earn 应暂停，警报持续，TimeBoxer 应尝试回到原生全屏。
7. 返回 TimeBoxer 并确认继续：警报停止，Earn 从暂停处继续，而不是把切走的时间算入完成时间。
8. Earn 中合盖或让 Mac 休眠，再唤醒：倒计时应暂停，不应因休眠获得时间，也不应持续误响警报。
9. 启动 Play，确认游戏和受保护网站在 Play 截止前不触发警报；退出 TimeBoxer 后重新启动，旧 Play 权限不得继续存在。
10. 退出全屏、最小化或尝试从菜单退出：Earn 应恢复全屏；退出 TimeBoxer 应要求家长 PIN。
